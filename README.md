# boigxtic

Portal d'apps de classe de J Alcolea (Ins Júlia Minguell).

**Web:** https://profejuanalcolea.github.io/boigxtic/

## Afegir una app
1. Si l'HTML és teu: crea una carpeta dins de la matèria (p. ex. `mates/pizzeria/`) i puja-hi el fitxer amb el nom `index.html`.
2. Obre `apps.js` i afegeix-hi una línia amb el títol, la matèria i l'adreça (`mates/pizzeria/` o un enllaç extern `https://...`).
